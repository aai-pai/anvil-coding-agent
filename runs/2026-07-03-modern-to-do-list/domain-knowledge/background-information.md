# Project Request

modern to-do list

## Assumptions

- The application will be a web-based SPA using React and Tailwind CSS.
- Features include creating, reading, updating, deleting (CRUD) tasks, and marking tasks as complete.
- Data will be persisted using browser localStorage.
- The UI will be a minimalist, single-column layout with a dark/light mode toggle.
- There is no user authentication or cloud synchronization.
